Added `GleeVerifierActionProvider` (`glee-verifier`), allowing autonomous software engineering agents to gate code submissions and verify git unified diffs against path rules, security boundaries, and assertions via GLEE's live x402 acceptance verifier ($0.05 USDC on Base mainnet) with Ed25519 cryptographic acceptance receipts.

Enforced operator-trusted payment terms before signing and authenticated Ed25519 receipts with exact request and result binding. Missing trust configuration fails before payment.
