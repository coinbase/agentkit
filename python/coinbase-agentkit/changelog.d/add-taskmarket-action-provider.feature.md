Added a new Taskmarket action provider for interacting with the Taskmarket onchain agent task marketplace on Base (USDC rewards). The provider supports browsing open tasks and fetching task details through the public Taskmarket REST API, and creating tasks through the official first-party taskmarket CLI, which owns the wallet and performs x402 payments. Task creation is gated by an explicit confirmation flag and a maximum spend limit (TASKMARKET_MAX_SPEND_USDC).
