# DefiLlama Action Provider

Provides actions for interacting with the DefiLlama API to fetch protocol TVL, protocol search, and multichain token prices.

## Actions

- **`find_protocol`**: Search for DeFi protocols on DefiLlama by name.
- **`get_protocol`**: Fetch detailed information and TVL breakdowns for a specific protocol.
- **`get_token_prices`**: Fetch current token prices across multiple chains (Ethereum, Base, Solana, Arbitrum, etc.).
